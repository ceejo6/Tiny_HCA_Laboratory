# Conway's Game of Life/Standard Rules

Hello!

If you have found my simulator, you have most likely tried many other available Game of Life Simulators or have perhaps even created your own.
My goal is not to create something better than those options, just something made for a different purpose.
This simulator was designed to provide a couple different things that I feel a serious Game of Life player would appreciate:

    1. A powerful feature stack that provides nothing more and nothing less than 99% of users would ever need.
    2. A fluid and intuitive experience.
    3. A polished and bug-free codebase.
    4. Complete access to the JavaScript/TypeScript engine via the in-game programming console.
    5. An option in a drop-down menu to select MicroPython as a language in the programming console.
    6. An option in a drop-down menu to select mruby as a language in the programming console.
    7. A well optimized backend codebase that makes use of the language Rust to store data via SQL and improve overall performance.
    8. A solid two branch path between a standalone executable you can run seamlessly on mobile/tablet or even on desktop/laptop, and a fully packaged desktop application that provides a few more powerful features.
